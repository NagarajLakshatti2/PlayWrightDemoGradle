- Try it Yourself interactive editor

### Automation Testing Practice - https://practice.expandtesting.com/

### XQA - https://xqa.io/
- 40+ real-world scenarios
- Shadow DOM, nested iframes, dynamic elements
- 100% free, no signup

### Way2Automation Practice Lab - https://way2automation.com/practicesite/

- Tab switching and popup handling

### Fun UI Playground - https://funui.dev/
- Themed UI challenges
- Bug-hunt pages
- No signup required

### WebDriver University - https://www.webdriveruniversity.com/

- Used by thousands of testers

### QA Playground - https://qaplayground.com/

### SoftwareTestPilot - https://softwaretestpilot.com/practice

## 🔌 API Automation Practice Websites

### JSONPlaceholder - https://jsonplaceholder.typicode.com/
- Classic fake REST API
- Posts, comments, albums, todos
- Supports all HTTP methods

### Mockfly API Hub - https://mockfly.dev/api-hub/
- Free public mock APIs
- Pagination, forced status codes, delays
- No signup required

### Fun API Playground - https://funapi.dev/
- 39 mock REST APIs
- Auth, webhooks, GraphQL, event streams
- Interactive docs, every HTTP status code

### FreeAPI - https://freeapi.app/
- Production-style endpoints
- Auth, e-commerce, social, todos
- No API keys, no quotas

### API Testing Playground - https://api.qaautomationlabs.com/
- Built specifically for QA practice
- Auth/JWT, pagination, filtering
- Code generation in 14 frameworks
- Demo login: qa@demo.io / Password123

**Note:** These are all free practice websites where you can run your automation scripts without needing any setup or API keys. Perfect for learning and practicing!
